# 使用政策

**生效日期：2026 年 8 月 10 日**

本《使用政策》（Acceptable Use Policy，简称"AUP"）适用于通过 Kiro.bus 发送请求的所有人，包括取 API key 的个人用户、拼车的车友、以及通过 API 或 Webhook 集成本平台的任何人。

制定本政策有两个理由：保护用户的安全，以及与上游 Vendor 和模型厂商透传给我方的条款保持兼容。我方通过自动检测、人工审核和流量监控执行本政策。违反可能导致内容被拦截、速率被限、账号暂停、永久封禁，情节严重的将移交执法机关。

## I. 通用禁止事项

以下适用于每个用户和每个用例。使用 Kiro.bus 时不得：

### 1. 违反法律
从事或协助违反您所在国家或地区法律的任何活动，包括但不限于毒品贩卖、武器贩卖、人口贩卖、儿童性剥削、洗钱、知识产权侵权、骚扰、诈骗、赌博、传销。

### 2. 攻击关键基础设施
攻击、破坏或干扰关键基础设施，包括电力、电信、医疗、交通、供水、金融、选举、政府系统及其控制系统。

### 3. 危害计算机或网络系统
开发、协助或自动化：漏洞利用、社会工程、恶意软件、勒索软件、拒绝服务攻击、僵尸网络、未授权入侵、绕过安全控制、或以规模化自动化损害他人系统的行为。

### 4. 研发武器或军事用途
研究、设计、生产、测试或采购武器、爆炸物或危险材料；用于指挥控制、目标锁定、自主武器系统，或化学、生物、放射性、核（CBRN）领域。

### 5. 煽动暴力或仇恨
煽动、宣扬或美化对任何个人或群体的暴力，或基于受保护特征（种族、族裔、宗教、性别、性取向、残障等）对人进行贬低、骚扰或歧视。

### 6. 侵犯隐私或身份权利
跟踪、骚扰或欺凌个人。未经同意收集、聚合或出售他人的个人信息、生物特征、健康数据、精确位置或通信内容。冒充真实人物或生成用于混淆真实身份的内容。

### 7. 危害未成年人
制作、传播或协助任何涉及未成年人性化、剥削、诱骗或伤害的内容，包括儿童性剥削材料（CSAM）。零容忍。违规者将被封禁并被上报至相关机关。

### 8. 造成心理伤害
自动生成或传播鼓励自残、自杀、饮食失调的内容，或有针对性地对他人进行心理攻击。

### 9. 制造或放大虚假信息
大规模制造或传播虚假、误导或伪造的内容，包括深度伪造、以及针对公共卫生、选举、司法程序、公共政策或公职人员的内容。

### 10. 干扰政治程序
干扰选举、大规模伪造舆论、在隐匿自动化的前提下开展自动化游说或选民接触、或大规模生成政治竞选材料。

### 11. 用于被禁止的执法或监控
构建预测性警务系统、量刑/假释/羁押辅助决策系统、社会信用评分系统、用于跟踪私人的面部识别、生物情绪识别、大规模监控或战场指挥系统。

### 12. 从事欺诈或欺骗
钓鱼、伪造身份、伪造评价、垃圾邮件、伪造文件、虚假交易、传销，或任何对他人进行欺骗、误导或剥削的行为。

### 13. 滥用平台
不得试图：
- 绕过或削弱我方的安全机制；
- 越狱或以 prompt 注入方式违背模型运营方的策略；
- 通过未授权方式提取模型权重、系统提示、隐藏规则或训练数据；
- 抓取、克隆、训练、微调或蒸馏上游厂商已明确禁止此类用途的模型；
- 超过我方公开的速率限制、配额或合理使用边界；
- 规避我方的计费、退款逻辑或风控（包括注册多账号刷注册积分、邀请积分或试用额度）；
- 操纵质保逻辑以骗取本不应获得的补车或退款。

### 14. 生成涉及真实人物的露骨性内容
未经真实、可识别人物同意，不得生成描绘该人物的露骨性内容；不得生成涉及未成年人的性内容（见 §7）。经 Vendor 与上游模型厂商同时允许的成人自愿性内容，须遵守他们的政策，不在此列。

## II. 高风险场景的额外要求

如果您的应用会影响他人的生命、生计、人身安全或法律权利，仅仅"不违规"是不够的，还必须：

- **保留合格的人工审核环节。** 具备相关专业资质的人员必须在结果影响任何真实决策之前进行审核；
- **在每次会话开始时明确披露 AI 身份**，如果输出直接呈现给终端用户。

高风险场景包括：

- **法律。** 法律解释、合同起草、或产生法律后果的建议。
- **医疗。** 医学诊断、用药建议、心理治疗或临床决策。一般健康科普不在此列。
- **金融。** 投资建议、贷款决策、征信资格、保险核保或理赔决策。
- **就业和住房。** 简历筛选、招聘决策、租赁或按揭资格。
- **教育评估。** 标准化考试、招生录取或专业资质认定。
- **新闻和媒体。** 以真实署名或品牌自动生成公开发布的内容。

## III. 其他强制披露

- **面向消费者的对话产品**必须在每次会话开始时告知用户其正在与 AI 交互。
- **面向未成年人的产品**必须遵守适用的儿童保护法（COPPA、GDPR-K 等），并落地年龄门槛、内容过滤和家长控制。
- **自主代理（Autonomous Agent）。** 由自主代理执行的请求同样受本政策约束。作为部署方，您对代理使用您的 key 所做的行为负最终责任。

## IV. Vendor 与模型厂商的专项政策

Kiro.bus 路由到独立的 Vendor，Vendor 再路由到独立的模型厂商。他们各自都有自己的使用政策，这些政策同样透传给您。

- 上生产流量前，先阅读该 Vendor 的条款和每一个模型厂商的使用政策；
- 如 Vendor 或模型厂商禁止某种用例，即使本政策未列出，您也不得通过该路由使用该用例；
- 如 Vendor 或模型厂商更新政策，我方尽力反映；不承诺时效性。

## V. 处置与申诉

基于自动检测、人工审核或上游厂商通报，我方可能采取以下措施：

- 拦截或过滤具体请求；
- 对账号或 API key 施加速率限制；
- 临时暂停或永久封禁账号；
- 追回因违规获得的持续退款或积分；
- 严重伤害情形下移交执法机关。

如果您认为处置存在错误，可以在[社群](/community)渠道申诉，或在 GitHub 仓库提 issue。我方会在合理时限内审核，按事实处理。

## VI. 变更

我方会随上游政策和适用法律的变化持续更新本政策。新版本生效后，继续使用本服务即视为接受。
