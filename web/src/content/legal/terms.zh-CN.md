本《用户协议》（以下简称"本协议"）是您（"用户"）与运营 Kiro.bus 的开源社区（合称"我方"）之间就您使用 Kiro.bus 网站、控制台、API、Webhook 端点及相关工具（合称"本服务"）达成的协议。您注册账号、生成 API key 或以任何方式使用本服务，即视为已阅读、理解并同意本协议。

## Kiro.bus 是什么（以及不是什么）

Kiro.bus 是一个**开源共享的 API key 拼车工具**，职责范围有限而具体：

- **我方不生产 API key。** 通过 Kiro.bus 交付的所有 key 都由独立的上游 vendor（下称"Vendor"）签发。我方并非 key 的发行方、发布方或经销商，与任何 Vendor 也不存在股权或代理关系。
- **我方负责路由，不负责制造。** 平台提供的每一项功能 —— 取 API key、路由、存活探测、质保补车、账单 —— 都是构建在 Vendor 和开源 API key 池项目 `kiro.rs` 之上的路由与记账层。Vendor 和 `kiro.rs` 都是独立的第三方。
- **我方不是 Vendor，也不为 Vendor 背书。** 任何 key 的可用性、价格、质量、寿命、条款都由发行的 Vendor 自行决定。我方公开实时可用性和有效成本信号供车友参考，但不对任何 Vendor 的经营状况、可持续性或输出内容作任何陈述或承诺。
- **我方不隶属于任何上游模型厂商。** 服务中如出现 Anthropic、OpenAI、Google、AWS 等名称，或任何具体的模型、产品、商标，均为描述性引用。Kiro.bus 未获得任何上述厂商的授权、认可或赞助。

如果您需要 SLA、与 Vendor 的直签合同、或来自模型厂商的官方支持，Kiro.bus 不是合适的工具 —— 请直接联系相应的 Vendor 或厂商。

## A. 谁可以使用本服务

本服务面向**个人用户**，用于与其他个人一起分摊 Vendor key 的费用，或为自己取一把 key。

## C. 本服务如何运作

- **取 API key。** 您请求一把 API key，我方从 Vendor 取一把回来，交付方式三选一：明文当场拿走、推入您自己的 API key 池、或放进您与他人共享的"拼车"（bus）。每一次取 key 都是对 Vendor 的路由动作。
- **拼车（bus）。** 同一辆车的车友共享同一个 Vendor 账号的费用。并发数、速率限制（RPM/TPM）、配额均按 Vendor 账号计量，同车车友共享。这是 Vendor 账号本身的属性，非我方可控。
- **质保与补车。** 每一把交付的 API key，我方在质保窗口内监控其存活。若 API key 在质保窗口内失效，系统自动补一把新的并按比例退还已扣积分。质保仅覆盖我方探针能观测到的失效情况；我方不对 Vendor 的可用时长、价格或适用性作承诺。
- **明文提取（handoff）。** 如您选择明文提取一把 key，我方仅交付一次并立即删除本地副本。提取后我方不再监控、不再补车、不再退款 —— 该 key 完全归您。
- **账单（ledger）。** 每一笔积分事件（充值、取 API key、补车、退款）都写入您的钱包账本，随时可在控制台导出。

- **模型厂商政策（Anthropic、OpenAI、Google、AWS 等）通过 Vendor 透传给您。** 如模型厂商要求下游披露、地区限制或内容策略，作为 key 的最终使用者，履行相应义务是您的责任。
- **我方不使用您的输入或输出训练模型。** 我方不读取、不留存、不将您经由本服务的 API 请求内容用于任何模型训练。

## E. 积分、充值与退款

- 本服务以**积分**计费（`1 积分 ≈ $0.14`，以美元结算）。每笔充值的明细（积分数、支付渠道手续费、到账数额）会在支付前完整展示。
- 支付渠道手续费是我方代收代付给渠道的 **pass-through**。积分本身是我方的。
- 退款规则：
  - **反悔：** 积分未使用的，可在充值后 30 天内申请退款。退款走原支付通道，扣除不可回收的渠道手续费。
  - **质保退款：** 自动执行，退回到您的钱包积分，不退回银行卡。
  - **超过 90 天：** 退款需身份核验，反欺诈规则下可能被拒。
  - **已经消费掉的积分**（已完成的取 API key、handoff、拼车轮次）**不退**。
